# CareerQuest-Django-Application-project
CareerQuest-Django Application project
CareerQuest is a web-based career path recommendation tool designed to help users discover which field they may be best suited for based on their interests. 
It uses a short quiz to match users to fields such as Technology, Healthcare, Creative & Design, and more.

Features
25-question quiz with career-based scoring

Personalized results with recommended career fields

Descriptions for 10 career categories

User registration and login (optional)

Saving quiz results for logged-in users

Responsive UI with light/dark mode toggle

"Contact Us" Gmail integration


Technologies Used
Django (Backend)Python

HTML/CSS/JavaScript

SQLite (Default Django database)

Git & GitHub
